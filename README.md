# Assets CDN

## Catálogo de fotos (`parklandvoyage/img-catalog.json`)
Fotos reales con licencia libre para reutilizar en guías y herramientas. Cada entrada: parque, atracción (si es de una concreta), qué se ve, tamaño, orientación, si sirve de portada 16:9 (`hero_ok`), de dónde viene (`commons`, `flickr`/`openverse`, `geograph`) y dónde se usa (`alturas`, `guia`). Autor, licencia y página de origen están en `img-credits.json` con el mismo nombre de archivo. Al añadir fotos nuevas, añádelas a los dos archivos.
